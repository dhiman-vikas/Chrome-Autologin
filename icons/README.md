# Icon Placeholder

To create the actual icon files:

1. Open `icon-generator.html` in your browser
2. Download all three icon sizes
3. Place them in this `icons/` folder as:
   - icon16.png
   - icon48.png
   - icon128.png

Alternatively, you can create your own PNG icons at these sizes using any graphics software.

## Icon Design Guidelines

- Use a simple, recognizable design
- Ensure visibility at small sizes (16x16)
- Use colors that stand out in browser toolbar
- Consider both light and dark browser themes
- Lock or key symbol recommended for security extensions
