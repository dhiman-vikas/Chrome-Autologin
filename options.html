Generic Auto-Login

Define login profiles: the pages in the sign-in sequence and the credentials to use

Security Notice:

Credentials are encrypted and stored locally in your browser. They are never sent to any server. The encryption key is stored in the same browser profile, so only use this on a device you trust.

When off, logins only run when you press "Trigger Login Now" in the extension popup.

Login Profiles

A profile is one website login. Step 1 is the entry page: when its URL is opened, the login starts. Each further step runs when the browser reaches its URL (for example username page, password page, authenticator code page). Each step runs once per login attempt.

No profiles yet. Click "Add Profile" to create one.

Configuration Help

  • URL pattern (wildcard): https://example.com/login matches that page ignoring any query string. Use * as a wildcard, e.g. https://*.example.com/signin*.
  • URL pattern (regex): a JavaScript regular expression tested against the full URL.
  • Selectors: leave empty to auto-detect fields (email/text, password, one-time-code inputs and submit button). Provide a CSS selector such as #username if auto-detection picks the wrong element.
  • TOTP secret: the Base32 key shown as "Can't scan the QR code?" when setting up an authenticator app, e.g. JBSWY3DPEHPK3PXP.
  • Reload tabs that were open before installing the extension.
